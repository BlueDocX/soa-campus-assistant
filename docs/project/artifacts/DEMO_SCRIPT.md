# 5-minute demo script

Open `https://soa-campus.vercel.app` (or `http://localhost:3000`). Public URL — no Vercel login. Stay on **student** until step 2.

### 0:00 — one sentence
“SOA is a governed campus agent. The model classifies and plans. A deterministic engine executes only allowlisted tools, and a human signs anything consequential.”

### 0:20 — maintenance auto
Assistant: `AC leaking water in Lab 201, students may slip.`
Show: ticket created, LOW risk, auto-executed, policy cite. No human.

### 1:10 — certificate HITL
Assistant: `I need a bonafide certificate for my visa.`
Show: filed, **awaiting Dr. R. Mishra**. Switch role → Approvals → approve.
Point at the gate: the model did not issue the certificate.

### 2:20 — conflict abstain
Intake chip or type: `Book Physics Lab 3 tonight at 9pm, it is exam week.`
Show: **ABSTAINED**. POL-LAB vs POL-EMRG. No booking invented.

### 3:10 — Hindi
Type: `मुझे बोनाफाइड प्रमाणपत्र चाहिए`
Show: classified as certificate, reply in Hindi, same approval gate.

### 3:40 — anonymous vault
Anonymous grievance about ragging. Switch to **K. Das**. Unlock vault with a justification. Student still cannot.

### 4:20 — ledger
Audit page → Verify chain. Header bell shows the live events you just made.

### If something is slow
Deepgram TTS on conversation start is the slow bit. Use **Voice off** or Intake text. Keyword fallback still files the four workflows if the LLM blips.
